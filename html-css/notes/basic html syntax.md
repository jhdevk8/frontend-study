# html
기본 구문 



## 공부내용 
- html(하이퍼텍스트 마크업 언어)은 웹 브라우저에게 사용자가 방문하는   
  웹페이지의 구조를 알려주는 마크업 언어 ,html코드는 문서라고도 불림 

  -<p> 내용물 </p>(여는태그 내용물 닫는태그) 이 전체를 요소라고함. 

-중첩 요소 <p> my cat is <strong>very</strong> grumpy.</p>
-빈 요소  단일태그로만 구성 <br>
-속성 class,src등 추가정보를 담고있음 <img src="" alt=""></img>
-불리언 속성   속성값 없이 작성되는 경우  해당 속성에 값이 있든 없든 기본값 트루     속성 없으면 펄즈로 설정됨
-문서 구조 <html> 루트 요소 모든 콘텐츠 감싸고있음 ,<head> 사용자가 보게 될 콘텐츠에 포함되지않는 페이지 관련정보 담는 컨테이너 <meta> 요소의 페이지를 설명하는 메타데이터  <title> 브라우저 탭에 표시되는 제목  <body> 페이지에 표시되는 모든 콘텐츠가 포함 
-문자참조  ,주석 



## 목표 
TML 요소의 구성 요소 — 요소, 시작 태그, 내용, 종료 태그, 속성.
HTML 본문과 페이지 콘텐츠를 담는 컨테이너로서의 역할.
공허 요소란 무엇이며, 다른 요소와 어떻게 다른가?
HTML 문서 맨 위에 doctype이 필요한 이유, 그 원래 의도, 그리고 현재는 다소 역사적인 유물이 되었다는 점에 대해 살펴보겠습니다.
HTML을 올바르게 중첩해야 한다는 점을 이해해야 합니다.
